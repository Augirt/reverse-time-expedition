# 逆时远征 · 可玩 Demo

**[点击开始试玩](https://augirt.github.io/reverse-time-expedition/)**

当前版本：v0.17.0 · [提交反馈](https://augirt.github.io/game-feedback-hub/)

赛博朋克像素风六边形战术游戏。带领推拿技师、守卫、医师和骇客，预见敌人意图，消耗时间改写未来。默认游玩过去、现在、未来三幕十五关。

- 新局先确认一个起手协议；已有本地记录可继续。每关选择能力成长，第五、第十关选择后接续下一幕，第十五次选择归档下一正式新局可用的一次性模块蓝图。
- 点选角色，在底部技能区选择行动后到棋盘指定目标；四项指令保持可见，也可按 1 / 2 / 3 / 4 切换。
- 指向地格预览完整连锁，点击执行；手机点选后确认。利用推送板、电容罐和敌方锁定地格。
- 使用「撤销一步」或「提前行动」调整决策，留意时间与污染。
- v0.14.0：五关分别为清敌、双节点撤离、精英斩首、双闸解封与封存执行官。三起手协议、六模块与有限II级让牵引、回响、碰撞、病毒和爆炸产生组合；保留普通射击与原技能，不增加免费AP。三项T1逐步加入，第四关必见T2护卫，旧改造由后续同职责敌人继承；下一战在成长选择前锁定。
- 第一幕自动保存当前战场、成长与改造账本、撤销历史和下一敌步骤；在同一浏览器刷新可继续。不同种子、难度、费用规则或同局重试，都在确认协议后才替换旧记录。存储不可用会明确提示；旧三关、独立练习和演练不覆盖正式战役存档。
- v0.15.0：正式远征为过去与现在两幕十关；第五次成长进入第六关，保留能力、队伍和累积改造，第十次成长后归档。现在篇含单节点撤离、三节点、双精英、有序校准与审计Boss；新三模块、明确满槽替换和两种终章III深化。敌改造累计九项，职责承载最多三条，第九关T3必见、第十关继承。旧第一幕存档保留战斗与原报价，完成档显式继续不重复领奖；未来篇后续扩展。
- v0.17.0：新局分散第4／11关目标路线；成长报价优先兼顾深化、联动与探索，减少刚卸装又换回。奖励与技能直接说明费用、范围、触发和升级差值，完整规则及累计机制按需展开。正式远征回时上限10、旧三关8，修复回合恢复倒扣；旧档保留原战场与待选奖励。按90–120分钟目标调校，真人时长尚待验证；新Boss本版仅完成候选设计，未加入随机池。
- v0.16.0：未来五关接续为完整十五关，原五关和十关存档保留原计划、报价与战场，完成档显式继续下一幕且不重复成长。九条旧机制加一项独立同步护幕设施，共10个唯一机制与14次公开进化；设施每敌阶段末补盾，花1AP校准永久关闭，终战沿用四乐手仅这一项额外场景规则。第三幕有限III深化与终局蓝图实装，蓝图仅新局协议确认使用时装I并占槽，与战役同次原子提交，失败/重试/备份不退款。
- 旧三关模式（v0.13.0）：第二关最多两对独立弹道屏障A/B，安全检查失败整对省略；开关占位仍可操作，关闭和撤销分别记录。默认借时仍每次1时间，可在“远征与种子”选择全队本轮1/2/2/2费用试验，规则整局锁定并写入分享链接。普通AP与撤销费用不变；第三关不随机投放屏障。
- v0.12.0：连续三关远征与三关独立练习全部开放，前两关选择不重复奖励。终战四名女子乐手拥有贯穿、隐身增幅、固定音爆与蓄能全图攻击；击破成员解除合奏减速。练习退出可恢复本页原远征，刷新不续玩。
- v0.11.0：正式地图扩至61格；第二关新增持久3盾的神经漫游者，有盾时拒绝近战，公开病毒注入和下回合结算预报。新镜头保证棋盘、人物与状态完整显示；旧地图链接保留种子并提示确认新规则。
- v0.10.0：医师主动移动缩为1格，仍消耗1 AP；友方只选人下达指令、敌方保留详情卡。观测猎手更名推拿技师。熔断载体被击杀也立即原地爆炸，预览/连锁/撤销同步；篡改技能黑影复验通过。

- v0.8.0：固定弹道屏障演练（远征与种子 → 屏障演练）可选四人小队或四职业独存。保护格仅免疫枪械直伤，近战、入侵、击退和全职业开关可反制；预览分清零直伤与后续连锁，开关可撤销。
- v0.7.0：熔断载体相邻后蓄爆，留出完整一回合；击退改爆点，骇客干扰延迟（每轮一次、总计两次），当时击破可拆除（v0.10.0起改为死亡也爆炸）。自爆伤及双方并连锁电容罐；倒计时和完整范围同步预警。
- v0.4.0：枪手贯穿直线最多3格，重卫横扫前方3格并击退；攻击形状完整公开，推拿技师可旋转整片范围。
- v0.6.0：守卫新增2 AP救援换位，骇客新增2 AP干扰脉冲；点击身份技能选用，原技能保留1 AP。无目标与AP不足明确提示，手机确认显示实际费用。
- v0.5.0：移除左右常驻栏，战场铺开；单位详情按需查看，底部左侧选人与技能、右侧时间与回合控制。选技能后可随时切换或取消，生命数值和行动费用不变。
- v0.3.0：两战随机布局开局锁定，三种骨架搭配定向推送板；奖励前可看下一战地图。
- 右上角“远征与种子”可输入种子、重试此局或开始新远征；同种子、难度与生成版本可复现。
- 电容罐、药箱与时锚终端可交互；撤回移动或攻击可留下额外2伤的时间回响。
- 骇客叠加病毒并引爆；医师施加破绽，让推拿技师和守卫追击。查看敌方抗性后选择攻击方式。
- 敌人会集火、护卫、净化和有限换靶；响应公开，每敌每轮限一次，可用位移、干扰与意图篡改拆解。
- 地图支持以鼠标位置为中心的滚轮缩放（80%–200%）、按钮缩放、复位及放大后拖动，可切换标准战术与高压挑战。
- 点击「执行未来」推进回合；「作战手册」提供详细规则。
- 「单位图鉴」可回放 15 类单位的战斗动作，熔断载体还可单独播放蓄爆动作。
- v0.2.2：骇客与零日终端完成精细像素升级，可在图鉴暂停、重播和逐帧查看四种动作。

支持桌面与手机浏览器。当前为开发中 Demo，三幕十五关可本地续玩；种子链接只复现开局，不携带战斗进度。旧三关远征与独立练习保留原模式，刷新这些模式会重新开始。
