# 逆时远征 · 可玩 Demo

**[点击开始试玩](https://augirt.github.io/reverse-time-expedition/)**

当前版本：v0.5.0 · [提交反馈](https://augirt.github.io/game-feedback-hub/)

赛博朋克像素风六边形战术游戏。带领猎手、守卫、医师和骇客，预见敌人意图，消耗时间改写未来。

- 点选角色，在底部技能区选择行动后到棋盘指定目标；四项指令保持可见，也可按 1 / 2 / 3 / 4 切换。
- 指向地格预览完整连锁，点击执行；手机点选后确认。利用推送板、电容罐和敌方锁定地格。
- 使用「撤销一步」或「提前行动」调整决策，留意时间与污染。
- v0.4.0：枪手贯穿直线最多3格，重卫横扫前方3格并击退；攻击形状完整公开，猎手可旋转整片范围。
- v0.5.0：移除左右常驻栏，战场铺开；单位详情按需查看，底部左侧选人与技能、右侧时间与回合控制。选技能后可随时切换或取消，生命数值和行动费用不变。
- v0.3.0：两战随机布局开局锁定，三种骨架搭配定向推送板；奖励前可看下一战地图。
- 右上角“远征与种子”可输入种子、重试此局或开始新远征；同种子、难度与生成版本可复现。
- 电容罐、药箱与时锚终端可交互；撤回移动或攻击可留下额外2伤的时间回响。
- 骇客叠加病毒并引爆；医师施加破绽，让猎手和守卫追击。查看敌方抗性后选择攻击方式。
- 敌人会集火、护卫、净化和有限换靶；响应公开，每敌每轮限一次，可用位移、干扰与意图篡改拆解。
- 地图支持以鼠标位置为中心的滚轮缩放（80%–200%）、按钮缩放、复位及放大后拖动，可切换标准战术与高压挑战。
- 点击「执行未来」推进回合；「作战手册」提供详细规则。
- 「单位图鉴」可回放 9 类单位的待机、移动、攻击与受击动作。
- v0.2.2：骇客与零日终端完成精细像素升级，可在图鉴暂停、重播和逐帧查看四种动作。

包含第七码头和审计庭，支持桌面与手机浏览器。当前为开发中 Demo，地址栏保留种子和难度，刷新页面会从同局第一战重新开始。

本仓库只托管编译后的试玩网页与必要运行素材，不包含开发源码、完整设定文档或编辑器工程。
