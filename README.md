# 逆时远征 · 可玩 Demo

**[点击开始试玩](https://augirt.github.io/reverse-time-expedition/)**

赛博朋克像素风六边形战术游戏。带领猎手、守卫和医师，预见敌人意图，消耗时间改写未来。

- 选择角色，按 1 / 2 / 3 或点击行动栏切换移动、攻击和技能。
- 指向地格预览，点击执行；利用击退、碰撞和敌方锁定地格。
- 使用「撤销一步」或「提前行动」调整决策，留意时间与污染。
- 点击「执行未来」推进回合；「作战手册」提供详细规则。
- 「单位图鉴」可回放 8 类单位的待机、移动、攻击与受击动作。

包含第七码头和审计庭，支持桌面与手机浏览器。当前为开发中 Demo，刷新页面会重新开始。

本仓库只托管编译后的试玩网页与必要运行素材，不包含开发源码、完整设定文档或编辑器工程。
